# Roadmap

## Near term

- [ ] PDF metadata anonymity scan (beyond `.tex`).
- [ ] Optional DOI/arXiv online verification with recorded URLs and dates.
- [ ] More verified conference profiles (workshops, journals, regional venues).
- [ ] GitHub Action that runs `papercraft check --with-repro` on a paper repo.
- [ ] Artifact packaging checker (secrets, large files, excluded paths).

## Later

- [ ] Web UI for the ledgers and gate report.
- [ ] Reviewer-panel calibration study (baseline vs skill).
- [ ] Template registry with signed hashes for common venues.
- [ ] Import/export for Overleaf projects.

## Non-goals

- Generating fake experiments, citations, or reviews.
- Predicting acceptance.
- Replacing human peer review.
