# Camera-ready checklist

> Apply only after acceptance. Keep the submitted PDF as `submitted.pdf` for
> reference; never edit it in place.

## 0. Freeze and branch

- [ ] Tag the submitted commit/PDF hash: `shasum -a 256 main.pdf`.
- [ ] Create `camera_ready/` branch or copy.
- [ ] Record the venue's camera-ready deadline and extra-page policy.

## 1. Content corrections

- [ ] Every known issue in `paper_state/audit-log.md` has a status
      (`FIXED`/`WONTFIX`).
- [ ] Descriptions match the code (no "empties state" if the code truncates text).
- [ ] Ablations described as what they actually change (stress test vs module drop).
- [ ] Baselines' coverage and fallbacks disclosed.
- [ ] Placeholder data disclosed; no "live values" claim if values are placeholders.
- [ ] Claim wording matches evidence strength (abstract especially).

## 2. Numbers

- [ ] `check_numbers.py` green.
- [ ] Every table/figure regenerated from canonical JSON.
- [ ] Stale values removed; `bad_values` empty of hits.
- [ ] Rounding consistent; units and n visible.
- [ ] If a headline number changed: all occurrences updated + diff log entry.

## 3. Citations

- [ ] `check_citations.py --strict` green.
- [ ] Every `SUSPECT` key removed/fixed.
- [ ] Every `UNVERIFIED` key resolved or removed.
- [ ] Missing citations (datasets, instruments) added.
- [ ] BibTeX fields complete; no "et al." in author fields.

## 4. Floats

- [ ] `check_floats.py` green: no orphans, no missing files.
- [ ] Every figure/table has a `\label` and at least one `\ref`.
- [ ] Captions self-contained; message first.
- [ ] Figures regenerated by script; no hand-edited bars.
- [ ] Readable at print size; no color-only encoding.

## 5. Anonymity / ethics (if still anonymous)

- [ ] `check_anonymity.py` green.
- [ ] PDF metadata clean.
- [ ] Links, acknowledgments, grant IDs removed.
- [ ] LLM-use disclosure per venue.
- [ ] Data/consent/license statements correct.

## 6. Template / compliance

- [ ] Official template version for the current year.
- [ ] Style file unmodified (or documented exception).
- [ ] Page limit satisfied (content vs refs vs appendix).
- [ ] Checklist/reproducibility form complete.
- [ ] Supplementary correct format and deadline.

## 7. Build and package

- [ ] Clean build in `/tmp`; 0 errors; 0 undefined refs/citations.
- [ ] PDF page count and fonts checked.
- [ ] Artifact zip rebuilt from the current code/data.
- [ ] Artifact README commands run in a clean copy.
- [ ] Artifact excludes `paper_state/`, `.env`, logs, secrets.
- [ ] Hashes recorded (`main.pdf`, `artifact.zip`).
