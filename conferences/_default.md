# Default profile (venue-agnostic)

Use this only when the venue has no profile, or before the CFP is verified.
It is a **checklist**, not a rule sheet.

## Volatile rules — verify every item

| Item | Where to look | Record |
|---|---|---|
| Page limit (content, refs, appendix) | CFP "Submission" / "Formatting" | exact wording |
| Template + version | Author kit / Overleaf template | file name + version |
| Anonymity scope | CFP "Review" | main only? appendix? supplement? |
| Supplementary deadline/format | CFP | allowed? separate PDF? |
| Reproducibility checklist | CFP / submission form | required? fields? |
| LLM-use policy | CFP "Policy" | disclosure? forbidden? |
| Dual submission / arXiv | CFP "Policy" | exception? |
| Rebuttal shape | CFP "Review process" | text? length? new results? |
| Camera-ready | CFP "Accepted papers" | deadline, copyright, extra page |

## Stable standards (apply regardless of venue)

1. Every claim has evidence; every number has a source; every citation is verified.
2. One message per float; every float is referenced and generated by a script.
3. Limitations are specific (n, domain, construct validity, external validity).
4. Baselines are same-setting; controls change one variable at a time.
5. Anonymity includes PDF metadata, code URLs, acknowledgments, self-citations.
6. Page budget: cut related-work detail and implementation detail before controls
   or limitations.
7. Artifact: README, fixed seeds, cache-only path, license, no secrets.

## Verification checklist

- [ ] Official CFP opened; URL + date recorded in the profile.
- [ ] Every `VERIFY` field replaced with exact wording or `N/A`.
- [ ] Template version matches the CFP (not last year's).
- [ ] Anonymity checked on PDF text **and** metadata.
- [ ] Page count measured on a clean build.
- [ ] Rebuttal format known before reviews arrive.

## Common desk-rejection causes

- Over page limit (including references/appendix, depending on venue).
- Wrong template/version, or modified style file.
- Non-anonymous PDF, GitHub link, acknowledgments, or self-identifying data.
- Missing required checklist / reproducibility statement.
- Dual submission or arXiv policy violation.
- Supplementary uploaded after the deadline or in the wrong format.
